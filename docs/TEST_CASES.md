# Тест-кейсы

Проект: «Личный кабинет успеваемости студента».
Спринт 2: модель данных и локальное хранение (Room).

Автоматические проверки запускаются без эмулятора:

```bash
./gradlew testDebugUnitTest
```

45 тестов, все пройдены. Ниже — приёмочные тест-кейсы спринта и соответствие
автотестам. Столбец «Метод»: **А** — автоматический тест, **Р** — ручная проверка
(появится с экранами в спринте 3).

## Дефекты, найденные и исправленные в спринте

| ID | Дефект | Причина | Решение | Кто |
|---|---|---|---|---|
| D-01 | Сборка падала на этапе конфигурации: «Using kotlin.sourceSets DSL to add Kotlin sources is not allowed with built-in Kotlin» | KSP регистрирует сгенерированные Room-классы через `kotlin.sourceSets`, а встроенная поддержка Kotlin в AGP 9 это запрещает | В `gradle.properties` добавлен `android.disallowKotlinSourceSets=false` с комментарием; версия KSP выровнена под Kotlin 2.2.10 (2.2.10‑2.0.2) | LD |
| D-02 | Тест сохранности не запускался: `Method ... should be void` | `runBlocking` возвращал `Boolean` последнего выражения, тестовый метод получал не-`void` возвращаемый тип | У тестовых методов явно указан тип возврата `Unit` | QA |
| D-03 | Предупреждение компилятора: устаревший конструктор `Locale("ru", "RU")` | Конструктор помечен deprecated в новых JDK | Заменено на `Locale.forLanguageTag("ru-RU")` | LD |
| D-04 | Проверки на эмуляторе не выполнялись | На рабочей машине недоступна аппаратная виртуализация: эмулятор требует Android Emulator hypervisor driver / WHPX | Тесты уровня данных переведены на Robolectric (JVM, без эмулятора); инструментальный набор оставлен для устройства | QA |

## Ограничения проверок

* Тесты покрывают слой данных и правила ввода. Интерфейс появится в спринте 3 —
  после этого добавятся ручные тест-кейсы (Р) на экраны, навигацию и пустые состояния.
* Проверка на физическом устройстве не выполнялась: сборка APK проверена
  (`app/build/outputs/apk/debug/app-debug.apk`), запуск — задача спринта 3.
* Robolectric проверяет логику SQL/Room, но не реальное поведение конкретной
  версии SQLite на устройстве; для финальной приёмки (спринт 6) прогон
  инструментальных тестов на устройстве остаётся обязательным.
